Sobre a ferramenta e os Serviços de API do YouTube

A ferramenta de publicação do canal Caso Julgado (Publicador de Aulas) é um programa de uso interno, executado no computador do responsável pelo canal, que envia ao YouTube os vídeos produzidos pelo próprio canal (vídeos, Shorts, miniaturas, legendas e comentários). A ferramenta usa os Serviços de API do YouTube (YouTube API Services). Ela não é oferecida ao público e só é usada com a conta do próprio canal.

Termos de Serviço do YouTube e Política de Privacidade do Google

Ao usar a ferramenta, o usuário concorda com os Termos de Serviço do YouTube. O uso dos Serviços de API do YouTube também está sujeito à Política de Privacidade do Google.

Dados acessados, usados e compartilhados

A ferramenta pede, pelo login do Google (OAuth 2.0), apenas permissão para enviar e gerenciar vídeos, legendas e comentários do canal autorizado. Ela usa essa permissão somente para publicar o conteúdo do próprio canal. Ela não lê, coleta, armazena nem compartilha dados de outros usuários, espectadores ou canais, não usa cookies e não compartilha nenhuma informação com terceiros.

Armazenamento

O único dado guardado é o token de acesso fornecido pelo Google, mantido somente no computador do responsável pelo canal. Nenhum dado é enviado a servidores próprios ou a terceiros, além do próprio YouTube/Google.

Revogação do acesso e exclusão de dados

O acesso pode ser revogado a qualquer momento na página de configurações de segurança do Google: security.google.com/settings/security/permissions. Ao revogar o acesso, o token deixa de funcionar e é apagado do computador em até 7 dias. A exclusão também pode ser pedida pelo e-mail abaixo e será feita em até 7 dias.

Privacy Policy

Last updated: October 15, 2026

About this tool and YouTube API Services

The Caso Julgado publishing tool (Publicador de Aulas) is an internal program, run only on the channel owner's computer, that uploads the channel's own content to YouTube (videos, Shorts, thumbnails, captions and comments). This tool uses YouTube API Services. It is not offered to the public and is used only with the channel's own account.

YouTube Terms of Service and Google Privacy Policy

By using this tool, users agree to be bound by the YouTube Terms of Service. Use of YouTube API Services is also subject to the Google Privacy Policy.

Information accessed, used and shared

Through Google sign-in (OAuth 2.0), the tool requests only permission to upload and manage videos, captions and comments on the authorized channel, and uses it solely to publish the channel's own content. It does not read, collect, store or share data from other users, viewers or channels, does not use cookies, and does not share any information with third parties.

Storage

The only data kept is the access token issued by Google, stored solely on the channel owner's computer. No data is sent to our own servers or to any third party other than YouTube/Google.

Revoking access and deleting data

Access can be revoked at any time via the Google security settings page: security.google.com/settings/security/permissions. Once access is revoked, the token stops working and is deleted from the computer within 7 days. Deletion can also be requested by email at the address below and will be completed within 7 days.
